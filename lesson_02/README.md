# Домашнее задание 1
## Что делает программа
Программа - функция format_report, с помощью модуля calculator, она считает итоговую сумму поездки.
## Команды
| команда | что делает |
|---------|------------|
| создание окружения | py -m venv .venv |
| активировать окружение | .venv\Scripts\activate |
| поставить зависимости | pip install -r requirements.txt |
| запустить | python trip.py |
## Что выводится
Программа печатает построчно кол-во записей, итоговую сумму и среднюю трату.
